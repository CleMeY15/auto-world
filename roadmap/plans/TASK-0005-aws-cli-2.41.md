## Candidate and reason

Investigate the official amazon/aws-cli 2.41.0 Linux/amd64 release. AWS documents the versioned Docker Hub tags as immutable. The 2.38.5 image has 49 HIGH occurrences across 21 CVEs and 16 RPM names on f6fcd6ef. The 2.41.0 config declares the corrected AL2023.12.20261112 base. The official registry publishes index sha256:c5d442efed03350a3c3d7a42b23f42a8e7b76acf5dbb4b021f2641bcd36680ea, amd64 manifest sha256:eb3b4742dbfd983bcb79e2df22fbcfde9ad5b3f8277ff1d4050bd7f9cdd9c090 and config sha256:25c7966f5a6c335934d4a1b75584e12c3495a038df0848359d586d669821ffa4. Annotated release tag links to source commit 7e6f97cb7b149863b5133857b2095bca3f3cab47. The registry identity and tag-to-commit association each describe their own object. Source-to-binary provenance requires separate evidence.

2.40.3 also declares the corrected base. Prefer the maintained, current 2.41.0 candidate for qualification using the current-upstream preference in ADR-0026. This is a CLI minor upgrade. In particular the changelog changes S3 multipart responses for versioned buckets and adds sign-up/login behavior. The local service contract exercises explicit Seaweed S3 endpoints, synthetic credentials, conditional writes and authenticated reads. An unchanged entrypoint alone cannot establish this compatibility.

Primary sources: https://docs.aws.amazon.com/cli/latest/userguide/getting-started-docker.html and https://github.com/aws/aws-cli/blob/7e6f97cb7b149863b5133857b2095bca3f3cab47/CHANGELOG.rst. Archived observations, package mapping and limitations accompany this preparation.
