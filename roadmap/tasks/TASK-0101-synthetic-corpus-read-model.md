# TASK-0101 — SDK-backed synthetic corpus and query contract

Status: BLOCKED until TASK-0007 is Done on `main`. Priority: P1. Owner: Data/ingestion executor; independent architecture, data-rights and security review.

## Goal and dependencies

Create the smallest offline ingestion/provenance proof using the accepted Connector SDK and a versioned deterministic fixture corpus. Depends on TASK-0006 plan and TASK-0007 accepted on `main`; no TASK-0005 service is used. Own a small public `packages/demo-search-contract` for `DemoSearchQueryV1`, `DemoResultV1`, `DemoSearchResponseV1` and `DemoReadPort` declarations/validators only. Before API coupling, freeze a focused ADR for their semantics and compatibility/rollback; do not change the accepted V1 vehicle schema silently. TASK-0102 alone implements and tests `DemoReadPort` behavior.

## Acceptance and test strategy

- `runConnector` still calls an authenticated-current **test-only** authority port with an enabled structural registry fixture. The fixture is never authentic legal/operator evidence. Production import/build exclusion and blocked external-network egress are negative tests.
- Raw bytes stage before decode; every displayed accepted field has immutable observation/source/run/time/confidence/raw-hash provenance. Stable publication ID is source plus source listing ID; URL is never sole identity. Malformed input publishes nothing; contradiction retains both observations; withdrawal leaves historical evidence and removes only active projection.
- Exact replay/idempotency, partial/full reconciliation, revoked/expired authority, retention expiry, cancellation and fault injection preserve SDK semantics; in-memory success is never reported as durability or backup proof.
- SDK tests show committed unresolved `Listing` and listing-scoped observation evidence without creating/associating `VehicleEntity`; this is input evidence for TASK-0102, not a read-port pass. The public contract declares results keyed by `ListingId` with sanitized opaque evidence IDs/time/confidence/value and an envelope declaring `dataMode:"synthetic"`. Neither contract exposes internal raw hashes/source/run/snapshot IDs, VIN or unsupported make/model/year/location/photo/valuation fields. Query validators accept only explicitly frozen filters and sort/cursor semantics.
- Freeze a response envelope with `schemaVersion`, `dataMode`, fixture version, committed-projection `dataAsOf`, `complete|partial|stale` state, results, optional opaque cursor and bounded non-complete reason code. Define the freshness bound, incomplete-count behavior, compatibility/V2 rule and UI-visible meaning in the ADR; test stale/partial fixtures and reject silent `complete` fallback.
- Targeted contract tests, root lint/typecheck/tests/build, secret/dependency gates, independent reviews and `docs/validation/TASK-0101.md` evidence pass. Rollback removes only the demo composition and keeps accepted SDK contracts unchanged.
