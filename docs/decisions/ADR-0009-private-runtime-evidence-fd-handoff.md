# ADR-0009 — Fixed private runtime evidence descriptor handoff

Status: ACCEPTED, 2026-09-30; independent architecture and distinct Critic review APPROVE. Implementation and native archive acceptance remain pending.

The accepted PostgreSQL cold/SQL diagnostics retain two root-owned0600 receipts and a UID1000 SQL dump. The private UID1000 evidence intake has a closed29-payload inventory. Its contract must remain unchanged, and root must not write destinations in a user-controlled directory.

Use one fixed short-lived read-only root reader and a genuine UID/GID1000 worker through existing installed Node22/setpriv. Root opens only the three independently pinned historical sources O_RDONLY/O_NOFOLLOW, holds path/ancestor/full byte seals and passes already-open readonly FD slots3/4/5. The worker authenticates historical receipts with existing default validators, writes only exclusive private ext4 destinations and keeps all guards through the reviewed PREPARED/COMMIT/PUBLISHED/FINALIZE/RESULT handshake. Root never writes, deletes or accepts a destination on a receipt's instruction. No configurable CLI source, descriptor role, subject or expectation is provided.

Publication is provisional: the closed receipt stays PUBLISHED_AWAITING_SUPERVISOR_ACK. Only its matching final supervisor ACK after final root/worker seals, successful descriptor closure, child exit0/close and output EOF establishes this diagnostic copy result. A retained JSON without that ACK remains incomplete. Failures preserve originals and payloads; only a receipt proved to be this worker's newly created inode may be retired by UID1000. Foreign replacements and uncertain cleanup never become success.

This is an additive archive transport contract, not a new privilege service, image execution route, audit permission, admission or support activation. Readonly FD access does not make files immutable, and the shared administrator/UID boundary stays disclosed. PR123 historical source-bundle bytes are not replayed against the new live Git HEAD. External source/notices, official attestation and a second evidence copy remain separate closure gates.

The complete fixed input, actor, IPC, native inventory, bounds, validation and rollback contract is [the independently approved focused execution plan](../validation/TASK-0005A-POSTGRES-PRIVATE-RUNTIME-EVIDENCE.md). Its required final ACK is retained separately in the existing private root log and independently pinned after review. Receive gates reject pipelined/trailing bytes and open only after completed grant writes; RESULT stays locked until the parent writer completes FINALIZE plus EOF. Implementation may proceed within this contract; no native acceptance is inferred from approval or fixtures.
