## Scope and entrypoint

The existing static `/` component preview stays intact. The consumer demo lives at `/demo`, reached by an explicit local URL. A server-only runtime flag `AUTO_WORLD_DEMO=1` enables Search/Results/Detail/Saved and the proxy. There is no public environment URL or build-inlined flag. ## Protocol and read authority

Node Route Handlers expose POST `/api/demo/search` and GET `/api/demo/listings/[listingId]`. The only upstream is the literal `http://127.0.0.1:3210`, with the accepted corresponding API V1 paths. No target derives from headers/query/body/environment; no incoming header is forwarded. Detail uses the public `parseListingId` and encodes its single segment. Search JSON is bounded to8192 UTF-8 bytes before buffering. Unsupported media, unknown query fields, malformed input or route IDs fail closed. Preserve the bounded original search body for authoritative API strict JSON/query validation; permissive proxy parsing must not erase duplicate keys. Do not import API private source.

Upstream fetch uses `cache:no-store`, `redirect:error` and combined request-abort/7000ms timeout signals. No hidden retry or configurable destination. Responses are bounded before buffering (1MiB), fatal UTF-8 decoded and validated against the exact public wrapper/schema and route rules. Success is `{schemaVersion:1,requestId,data}`, with bounded valid API requestId and `parseDemoSearchResponse(data)`; detail has at most one result matching the requested ID and no cursor. The web-local HTTP parser rejects duplicate keys and exact-shape/domain violations in success/error wrappers. Upstream errors are validated then rebuilt with their validated requestId; local errors have exact {schemaVersion:1,requestId,error:{code}} and a fresh crypto req_ plus32 lowercase hex ID (never accepted from browser headers). Codes map exactly: invalid_query/invalid_cursor/invalid_request400, not_found404, method_not_allowed405, cancelled408, request_too_large413, unsupported_content_type415, read_unavailable503. Transport/invalid response is read_unavailable503; timeout is cancelled408. Unsupported methods including automatic Next HEAD/OPTIONS behavior get explicit405 handlers. Detail has no query parameters; search query fields exist only in the preserved body. Arbitrary bodies/status/headers/text never reach the browser. Local transport or invalid response yields neutral retryable503; timeout408. Cancellation never logs success. Rebuild only JSON Content-Type and `Cache-Control:no-store`, with no cookies/redirect/CORS/header passthrough. Require the actual Host header to be127.0.0.1 with an explicit valid HTTP port; incoming Origin, when present, must exactly equal http:// plus that validated Host. Reject cross-site Fetch-Metadata. Ignore Forwarded and all X-Forwarded-* entirely for destination, origin, telemetry and client identity, and never transmit them. Next16.3.8 synthesizes these headers itself; presence is not a rejection condition and its forwarded-derived request URL origin is not trusted. Mutants prove synthetic/hostile forwarded values cannot change upstream or response. The testable proxy factory accepts a fetch/clock/closed telemetry sink; Route Handlers supply fixed values and the server flag.

Runtime dependencies are only accepted public demo DTOs and the vehicle-schema ID validator. No web import of API/ingestion source, SDK, connector/test-support fixtures, raw values or source registry. Foundation production trace checks evolve narrowly to allow exact public compiled parser modules while rejecting fixtures/services/source-rights/test code. No dependency beyond existing workspace public contracts.

## Navigation and presentation

One bounded client island owns Search/Results/Detail/Saved. Local history/hash identifies screen and an optional validated public listing ID. Query stays in memory, never in URL/analytics/storage. Browser Back and in-app return preserve editable filters/results/scroll and trigger focus. Reloaded/direct detail hashes validate the ID and fetch only public detail; missing/withdrawn items stay honest. Saved is reopenable. Titles, main headings and focus follow navigation; hidden screens are not focusable.

Every screen persistently says `Données entièrement synthétiques. Aucun véhicule à vendre.` A local neutral vector is labeled `Illustration de démonstration`, without brand/model/photo claims. Cards show neutral publication names, observed price/currency and mileage/unit, or `Non disponible`. Evidence progressively discloses timestamps/values/observation confidence, contradictory observations and withdrawn/deleted/missing state. No VIN, model/year, seller CTA, source URL, Trust/Deal Score or verified-history wording. No raw/source/run/snapshot IDs. Ended history is reached from saved/detail, never made active in results.

Budget is maximum EUR minor units and mileage maximum km; no invented conversion. Only accepted stable sorts. Additional filters and unsupported free text use progressive disclosure. Nonempty free text stays editable and prevents submission with clear unsupported-syntax feedback; no invented filters or LLM. Deterministic number/domain validation shares the public query parser. Search is primary; Saved and Back remain shallow secondary actions.

A visible `Charger plus` consumes nextCursor only for the current accepted query. Append page results in API order and reject duplicate ListingIds/evidence IDs across pages. Require unchanged fixtureVersion/dataAsOf across continuation pages; state may become stale with age, then hide the complete count. Reset pagination on any submitted filter/sort change. Loading/error on a later page preserves acquired results and its retryable cursor; late responses cannot mutate a newer search. Never silently truncate a valid nextCursor or declare only the first20 results complete. Accumulation is bounded by the accepted10000-result projection ceiling; reaching an inconsistent ceiling fails closed with an explained restart/refine action. Positive first/middle/last pagination and duplicate/changed-snapshot/late-page mutants are UI-only contract tests, distinct from the real default-corpus E2E and the already accepted API41-publication proof.

## Local favorites

Only key `auto-world.demo.favorites.v1` is read/written. Exact canonical JSON is `{schemaVersion:1,listingIds:[...]}`, at most100 distinct valid public ListingIds in insertion order, <=8192 UTF-8 bytes. Reject unknown/prototype keys, sparse/duplicate IDs, payload/query/PII. Validate IDs with the shared public parser. Read after hydration/user interaction to avoid mismatch. Other keys and unknown future versions are never overwritten. Corrupt/oversize/denied/quota data gets explained recovery, never false persisted success. User reset targets only this versioned key; an unknown future version is preserved. Write failure keeps qualified session-only favorites; failed reads do not silently destroy stored data. Cross-tab events are validated/reconciled without rewriting invalid/future data.

Save/remove feedback is immediate (<100ms measured target). One in-memory removal undo restores insertion position, checks capacity and reports true persistence. Offline or flag-disabled Saved shows IDs and local remove/undo/reset only; detail is unavailable, with no offline fixture/cached inventory. Online detail failure never erases a favorite. Only the active online Saved screen loads details, with a maximum4 concurrent fetches, stable insertion order, no automatic retry and cancellation on navigation or ID-set replacement.100-ID tests prove the ceiling and per-item failure; offline/disabled Saved does not display cached DTOs as inventory. Undo reconciles against the current validated cross-tab state. A reloaded Results hash without an in-memory query returns to Search with an accessible explanation; valid global favorite clear requires explicit user confirmation or recoverable undo. Abort/late responses cannot overwrite newer query/screen state. Loading, slow>=750ms, offline, retryable error, empty, unavailable fields, partial/stale and storage states preserve context/stable geometry. Partial/stale never announce a complete total; show readable explanation/retry.
