## Security, observability and rollback

Parsers must return only stable sanitized issue codes/schema paths; no source text, raw payload, VIN or thrown exception text belongs in errors/logs. V1 does not verify a licence, fetch URLs or expose a public VIN projection. Registry activation, policy enforcement and raw-byte digest verification belong to later tasks. Contradictory observations remain immutable evidence; no implicit winner or identity resolution exists.

No backend workflow exists to instrument yet. Validation issues are the future ingestion metric/log boundary. No UI/a11y/visual or customer analytics gate applies to this internal package. Runtime/type/contract E2E, security review and reproducibility still apply. Compatibility and rollback are defined in ADR-0001: accept schemaVersion 1 only; revert before consumers couple to it, coordinate versioned readers/writers afterward; never delete historical evidence as a migration shortcut.
