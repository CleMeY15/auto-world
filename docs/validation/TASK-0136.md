## Code et frontières

Le [README du spike](../../connectors/leboncoin-spike/README.md) contient les recettes de collecte et replay. Le code repose sur notre extraction et Playwright libre, sans API commerciale d'annonces ou de scraping.

Le CLI utilise une navigation bornée à 30 s, contexte neuf, aucun cookie/profil importé, aucun retry ni résolution de challenge. Il bloque les images/media : profil distinct du navigateur cloud, sans effet sur l'essai réel qui n'a pas navigué. Une redirection peut être suivie par Chromium avant détection ; elle est rapportée puis la capture est refusée. Le zéro redirection strict n'est garanti que pour le GET urllib initial.

La version finale filtre les éléments rendus et les enfants libellé/valeur, scope les critères dans main, normalise les octets sauvegardés et distingue extracted/partial_capture. extracted exige les champs essentiels observés et aucune anomalie de normalisation. Ces ajustements sont vérifiés hors réseau, sans prétendre qu'ils ont été exécutés contre leboncoin.

## Limites et prochaine décision

- Échantillon de commodité : trois Porsche trouvées par URL dans un moteur de recherche. Les extraits du moteur ne sont jamais utilisés comme données acquises par le connecteur.
- Le contexte du navigateur cloud existait déjà ; son état d'authentification n'a pas été déterminé. Aucun cookie n'a été lu ni transféré.
- Galeries annoncées 5/6/16 photos, seules trois références visibles relevées par fiche. Aucun fichier photo téléchargé, aucune prétention de copie complète.
- VIN/plaque : pas d'OCR ni de recherche externe, pas de VIN observé dans les critères capturés. Cela ne prouve pas l'absence de ces éléments ailleurs dans l'annonce.
- Dates visibles de publication non normalisées automatiquement : les captures main time sont vides. L'heure de capture n'est jamais utilisée comme date de publication.
- Pas de découverte du catalogue, pagination, durée de disponibilité, suivi d'une modification à une autre date, débit, couverture ou robustesse prolongée.
- Le rejet d'un prix /mois porte sur le texte capturé ; une qualification universelle de la location ou du financement n'est pas démontrée.

**Prochain jalon avant de reprendre le développement général : exécuter ce CLI, sans session importée, dans l'environnement de déploiement choisi où Chromium peut démarrer.** Une réussite sur des fiches devra ensuite être répétée à plusieurs dates avant d'étudier découverte, débit et couverture. Aucun verdict de viabilité à long terme n'est émis à partir des trois observations cloud.
