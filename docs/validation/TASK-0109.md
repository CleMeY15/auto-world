## Implemented boundary

Results can select two or three publications, open a factual local comparison and return to the unchanged results. Selection is derived from the current accepted response, never a second authority. No new dependency, API, DTO, storage key, infrastructure or automotive-source permission.

- Selection is unique, bounded, immutable and ephemeral. It survives same-snapshot pagination and screen changes, but resets on every first-page request, saved-criteria restore and reload. Pending first-page requests lock old-result selection. A failed refresh can expose the old accepted facts again with original dataAsOf/error, not silently retained selected IDs.
- Availability is the accepted search's active point-in-time invariant. The existing parser rejects hostile non-active search results before selection; comparison introduces no lifecycle refresh/detail fetch.
- Exact comparisons distinguish unknown, incomplete, incompatible currency/unit, identical and different values without conversion, ranking or inferred vehicle identity. Tiny mileage and safe-integer minor-unit prices retain their exact distinctions.
- Price/mileage use the selected evidenceId's observation time/confidence. Authored make/model/year require the matching catalogue/release/attribution; a mismatch withholds the whole declaration. Authored provenance is separate and shown once per publication. Historical differing values are not claimed to be simultaneous contradictions.
- Partial, stale, offline, failed-refresh, unavailable catalogue, empty and below-minimum states remain explicit. Comparison performs zero new requests/storage writes; disabled demo retains local management with zero API calls. Analytics remains a closed no-op event/screen/outcome contract, without IDs/values/queries.
