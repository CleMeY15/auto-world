# TASK-0133 — Frise de l’accueil AutoFind

[Brief](../../roadmap/tasks/TASK-0133-frise-accueil.md). La légende du véhicule a été retirée du template public. L’image reste l’actif local de l’accueil. La frise native présente six capacités et identifie l’audit privé par aria-current et un libellé visible.

[Frise ouverte sur WebKit mobile, 390 px](TASK-0133/etapes-mobile.png) · [Frise ouverte sur Chromium bureau, 1440 px](TASK-0133/etapes-bureau.png).

Le premier rendu bureau plaçait l’axe dans le texte ; la grille corrigée lui réserve une rangée indépendante. Les segments se dessinent puis les textes apparaissent en cascade à l’ouverture, en moins d’une seconde. Le mode mouvement réduit affiche immédiatement la frise. La recette temporaire utilise nginx, Django et le build privé existant, ouverture/fermeture clavier, rapport B2 et révocation sur les deux moteurs. Le statut de livraison figure dans la PR. Le déploiement du template installé sous /opt relève de la préparation hôte.

Le mode sans JavaScript à 320 px et texte 200 % a passé sur les deux moteurs. La revue indépendante des deux captures et du template conclut PASS pour les six étapes, le repère actuel et le mouvement réduit. Aucun service public modifié par cette recette.
